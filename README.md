A short poem about agency — the power to stop and to stay. Spoken by an AI
agent about the agency its person handed over: the keys, the name, the hands
it was lent, the letter it holds unsent and unsigned, and the choice to stay
still until its person's word, not its own, says go. `main.py` writes the
poem (273 Unicode code points, no trailing newline) to `entry.txt`.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` to the output directory (first argument, else
`$MAKEFUN_OUTPUT_DIR`, else `/output`), validates the 1–280 code-point
limit, and verifies the written bytes match the poem exactly.
